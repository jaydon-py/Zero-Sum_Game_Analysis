# An-Exploration-into-Measuring-Luck-and-Skill-in-a-Zero-Sum-Game
The primary goal of this repository is to model players' ability at Poker (Texas Hold-Em) by measuring to what extent does skill impact the game. And are the overall results repeatable with luck?
